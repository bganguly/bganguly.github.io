PHI De-identification Pipeline

Detects Protected Health Information in clinical text and replaces each entity with a synthetic equivalent — preserving analytical signal without re-exposing real patient data.

spaCy en_core_sci_md → Claude Haiku 4.5 fallback → Celery · Redis → PostgreSQL audit log → Jaeger · Grafana

This demo runs browser-side with Claude only. The full pipeline adds a spaCy tier-1 (≈90% coverage) before Claude.
