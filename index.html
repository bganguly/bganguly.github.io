EDGAR 10-K Agent — AWS

Python
Agent Loop · Tool Use · live EDGAR retrieval · Eval

Agentic loop written from scratch — no LangChain, no pre-ingested data. The model decides at runtime when to call SEC EDGAR tools; each call fetches live 10-K filings, extracts sections (Risk Factors, MD&A, financials), and parses structured figures. Multi-turn reasoning continues until a final answer is emitted. Eval harness scores faithfulness and citation accuracy across runs. Provider toggle switches between Anthropic Claude and NVIDIA NIM — same loop, same tools, different model.
