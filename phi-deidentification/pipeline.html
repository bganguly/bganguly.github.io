PHI De-identification Pipeline

Two-tier detection: spaCy en_core_sci_md handles ~95% of entities at sub-15ms. Entities below the 0.85 confidence threshold fall back to Claude Haiku 4.5, which returns structured JSON. All detected entities receive a Faker-generated synthetic substitute — never blank redaction — preserving analytical signal. SHA-256 hashes of originals are stored in a PostgreSQL audit log.
